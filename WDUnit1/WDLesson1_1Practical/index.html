Web Technologies

HTML

HTML stands for HyperText Markup Language, which is the standard language used to
create and design documents on the World Wide Web. It provides the fundamental structure
of a website by using a series of elements and tags to define headings, paragraphs, links, and
images. When you visit a website, web browsers read the HTML code and translate it into the
visual, interactive pages you see on your screen.

  1. Headings
  2. Paragraphs
  3. Lists
  4. Classes
  5. Styles
  • Comments
  • Formatting
  • Colors
  • Images
  • Buttons

CSS

CSS, which stands for Cascading Style Sheets, is a standard web technology used to control
the visual presentation and layout of web pages. It works alongside HTML to determine how
elements look by defining styles for fonts, colors, spacing, and positioning. By separating
content from design, CSS allows developers to apply consistent styling across an entire website
from a single file, making it much easier to maintain and update.

  1. Selectors
  2. Borders
  3. Margins
  4. Padding
  5. Text
  • Fonts
  • Icons
  • Links
  • Tables
  • Display

JavaScript

JavaScript is a high-level, versatile programming language that is primarily used to create
interactive and dynamic content on websites. Alongside HTML and CSS, it serves as one of
the core technologies of the World Wide Web, enabling features like animated graphics,
interactive forms, and real-time content updates. While it originally ran only within web
browsers, the development of environments like Node.js allows JavaScript to be used for
server-side programming, mobile app development, and desktop applications as well.

  1. Loops
  2. Output
  3. Strings
  4. Timers
  5. Dates
  • Data Types
  • Maps
  • Sets
  • Errors
  • Math

Bootstrap

Bootstrap is a popular, free, open-source front-end framework used for creating responsive
and mobile-first websites. It provides pre-designed design templates for typography, forms,
buttons, navigation, and other interface components using HTML, CSS, and JavaScript
extensions. By offering a ready-to-use grid system and customizable components, it allows
developers to build consistent websites quickly without writing all the code from scratch.
